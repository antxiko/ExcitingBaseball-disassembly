# Los textos

Todos los textos de la ROM, en inglés, salvo el título y las regiones, que van en
casillas de kanji. En la ventana y en los carteles, el espacio es la casilla 0x06.

| Dónde | Texto | Traducción |
|---|---|---|
| la selección (0x84A9) | PLAYER SELECT | ELIGE JUGADORES |
| | 1PLAY VS.CPU.  PUSH TRIGGER1 | UNO CONTRA EL ORDENADOR: PULSA EL BOTÓN 1 |
| | 1PLAY VS.2PLAY PUSH TRIGGER1 | UNO CONTRA OTRO: PULSA EL BOTÓN 1 |
| | TO START GAME | PARA EMPEZAR |
| | COPYRIGHT 1984 @ CASIO | COPYRIGHT 1984 © CASIO |
| la ventana (0x93E2) | GAME SET | FIN DEL PARTIDO |
| | NICE / HOME RUN | ¡BIEN! / HOME RUN |
| | SELECT 1PLAYER TEAM | JUGADOR 1, ELIGE EQUIPO |
| | GAME OVER | FIN DE LA PARTIDA |
| | NEXT GAME A / RESET B | A: PARTIDO SIGUIENTE / B: VOLVER A EMPEZAR |
| | GAME CLEAR | TORNEO GANADO |
| la cuenta (0x90A1) | BALL, STRIKE, FOUL | BOLA, STRIKE, FALTA |
| la jugada (0x9119) | OUT, SAFE, CHANGE | OUT, SALVO, CAMBIO |
| el marcador | S, B, O | STRIKES, BOLAS, OUTS |
| | 123456789 | las nueve entradas |

En la selección, el título japonés (熱戦甲子園, *Nessen Koushien*) y CASIO en letras
grandes son casillas propias (0x8475); en la ventana, CASIO en letras grandes es el
texto 5 de la tabla.
